SendCUIEmail - Sender Quick Start

Encrypt & Send CUI Files

SendCUIEmail encrypts files for secure transmission of Controlled Unclassified Information (CUI).

What's in this folder:
  • Encrypt.bat - Double-click or drag files onto it to encrypt
  • Decrypt.bat - Double-click or drag files onto it to decrypt
  • Open_PowerShell.bat - Opens PowerShell in this folder

Encrypting Files

1
Start Encrypt.bat

Option A: Double-click Encrypt.bat - a file picker will open
Option B: Drag your files onto Encrypt.bat - skips the picker

2
Choose a password

Enter a strong password (8+ characters). Press Enter for an auto-generated passphrase.

3
Select CUI category

Choose the appropriate CUI marking for your files.

Output: The tool creates a timestamped folder with:
  • .Locked files - Your encrypted files
  • Decrypt_Instructions.html - Instructions for your recipient
  • CUI_Email_*.msg - Pre-formatted email draft (Windows/Outlook)
  • Password_Email_*.msg - Separate password email draft

Sending to Recipients

1
Open the CUI_Email draft

Double-click the .msg file. It opens in Outlook with attachments already added.

2
Add recipient and review

Enter the recipient's email. Review the attachments and delete the sender instructions at the top.

3
Sign/Encrypt if you have PIV/CAC

If you have a PIV or CAC card, click Sign (and Encrypt if you have their certificate).

4
Send the email

Send the CUI email with the encrypted files.

Password Delivery

The password MUST be sent separately from the encrypted files.

Compliant methods:
  • Phone call
  • SMS text message
  • In-person
  • S/MIME encrypted email (if you have recipient's certificate)
NOT compliant: Sending password in unencrypted email, even if separate from files.

Troubleshooting

No .msg files created?
Email drafts require Microsoft Outlook on Windows. On Mac/Linux, manually create the email and attach the files.
Recipient can't decrypt?
Verify they're using the correct password (case-sensitive). Have them try again with the exact password.
Need to decrypt your own files?
Double-click Decrypt.bat and follow the prompts.

SendCUIEmail - Secure CUI File Encryption

Encryption: AES-256-CBC (FIPS 140-2) • Key Derivation: PBKDF2-HMAC-SHA256, 100,000 iterations (NIST SP 800-132)
CUI handling per 32 CFR Part 2002 • No software installation required for recipients
