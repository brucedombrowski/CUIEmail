\dmsection{Decision}

Replace \texttt{README.md} with \texttt{Decrypt\_Instructions.html} for recipient decryption instructions.

\textbf{Status:} \textcolor{passgreen}{APPROVED}

\dmsection{Context}

Recipients receiving encrypted CUI files need clear instructions to decrypt them. The current \texttt{README.md} file:
\begin{itemize}
    \item Requires markdown rendering (GitHub, VS Code) to display properly
    \item Appears as raw text with formatting characters in Notepad
    \item Not user-friendly for non-technical recipients
\end{itemize}

\dmsection{Options Evaluated}

\begin{tabularx}{\textwidth}{l c X X}
\toprule
\textbf{Option} & \textbf{Size} & \textbf{Pros} & \textbf{Cons} \\
\midrule
README.md (current) & \textasciitilde2 KB & Simple, tech-friendly & Ugly in Notepad, requires markdown viewer \\
\textbf{HTML (selected)} & \textasciitilde5-10 KB & Universal browser support, styled, professional & Some orgs may block HTML attachments \\
PDF & \textasciitilde50-100 KB & Professional, prints well & Large file size, requires PDF reader \\
HTML + PDF & \textasciitilde60-110 KB & Maximum compatibility & Redundant, large \\
\bottomrule
\end{tabularx}

\dmsection{Rationale}

\begin{enumerate}[label=\alph*.]
    \item \textbf{Universal access}: Every Windows user has a browser (Edge is built-in)
    \item \textbf{Professional appearance}: Styled with CUI banner, color-coded steps
    \item \textbf{Copy-paste friendly}: One-liner in monospace code box, easy to select
    \item \textbf{Small footprint}: \textasciitilde5-10 KB with inline CSS
    \item \textbf{Self-contained}: No external dependencies, works offline
    \item \textbf{Fallback}: Password\_Email includes the one-liner if HTML is blocked
\end{enumerate}

\dmsection{Implementation}

\begin{itemize}
    \item Generate \texttt{Decrypt\_Instructions.html} instead of \texttt{README.md}
    \item Include inline CSS (no external stylesheets)
    \item Match QuickStart\_Guide.pdf visual style (CUI yellow banner, blue steps)
    \item Include file picker one-liner in copy-friendly format
    \item Update CUI\_Email.msg to reference HTML file instead of README.md
    \item Add ``Before You Start'' FAQ section to anticipate recipient questions
\end{itemize}

\dmsection{File Size Target}

\begin{itemize}
    \item Maximum: 15 KB (including all inline CSS)
    \item Expected: 5-10 KB
\end{itemize}

\dmsection{Compatibility}

\begin{itemize}
    \item \textbf{Windows}: Edge, Chrome, Firefox (all built-in or common)
    \item \textbf{macOS}: Safari, Chrome, Firefox
    \item \textbf{Mobile}: Standard mobile browsers
    \item \textbf{Offline}: Works without internet (inline CSS)
\end{itemize}

\end{enumerate}
