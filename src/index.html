CUIEmail
Lock Controlled Unclassified Information for email, and open locked files you receive.

Everything happens on this computer. Nothing is uploaded anywhere. Files are locked with AES-256 and a passphrase that you deliver by phone or text, never by email.

1 Choose the files to send

Drop files here, or click to choose
Word, PowerPoint, Excel, PDF, or any other file. Each file is checked for a CUI banner.
    How do I add the banner to a document?

    Word: Insert → Header, type the banner (for example CUI//SP-EXPT//FEDCON), bold and centered. Repeat in the footer. If "Different First Page" is on, add it to the first-page header too.

    PowerPoint: View → Slide Master, add a text box with the banner at the top and bottom of the master so every slide inherits it.

    Excel: Page Layout → Print Titles → Header/Footer tab, on every sheet.

    Designation indicator: on the first page add lines such as Controlled by: [your agency], CUI Category: ..., POC: .... This tool prints the same block in the email.

    How it works
    
      
    Files are locked in this browser using AES-256-CBC with an HMAC-SHA256 integrity tag, and a key derived from the passphrase with PBKDF2-HMAC-SHA256 (600,000 iterations). All of it uses the browser's built-in Web Crypto implementation. No file or passphrase leaves this computer.
    
      
    Password-based encryption is used when both parties cannot use certificate-based email encryption (S/MIME with PIV/CAC). When both can, prefer that.
    
      
    Marking rules this tool applies
    
      
      
        
    • Banner: CUI//[SP-]CATEGORY/.../LDC/.... Specified categories first (with SP-), then Basic; each group alphabetized; dissemination controls alphabetized. (32 CFR 2002.20(b); NARA CUI Marking Handbook pp. 5-12.)
      • 
        
    • The email body carries the banner at the top and the bottom and a designation indicator with "Controlled by", category, dissemination control, and POC. (32 CFR 2002.20(c),(d); NPR 2810.7 2.2.8; ISOO email tip sheet.)
      • 
        
    • The email is a transmittal document: it states that CUI is attached and that it is uncontrolled once the attachments are removed. (32 CFR 2002.20(j).)
      • 
        
    • The subject begins with "CUI" and must not contain controlled information.
      • 
        
    • REL TO and DISPLAY ONLY lists start with USA, then country trigraphs, then organization tetragraphs, alphabetized. (CUI Registry, Limited Dissemination Controls.)
      • 
        
    • Attorney-Client and Attorney-WP only with the Legal Privilege category; NOFORN never with REL TO or DISPLAY ONLY; FED ONLY never with FEDCON. (CUI Registry.)
      • 
        
    • Each attached document must already carry its own banner on every page. This tool checks Word, PowerPoint, Excel, PDF and text files for one and warns if it cannot find it. It never edits your documents.

    PowerShell fallback (Windows)
    
      
    If you cannot open this page (for example, the attachment was stripped and the web address is blocked), a Windows PC can unlock a file with PowerShell. Open the Start menu, type PowerShell, press Enter, then paste this whole line and press Enter. It asks for the file path and the passphrase.
